# Hospital Management System

Built a Hospital Management System with 10
interrelated tables, 20+ SQL queries, PL/SQL
Trigger for automated bed management and
Stored Procedure for bill generation.

## Tools Used

Oracle SQL | PL/SQL | Oracle Live SQL | Git | GitHub | VS Code

## Files

- 01_sequences.sql → All sequences
- 02_create_tables.sql → All 10 tables
- insert_data.sql → Sample data
- basic_queries.sql → Basic queries
- advanced_queries.sql → Advanced queries
- trigger.sql → Bed management trigger
- procedure.sql → Bill generation
- view.sql → Patient summary view

## Tables

DEPARTMENT | DOCTOR | PATIENT | WARD | APPOINTMENT
ADMISSION | NURSE | MEDICINE | PRESCRIPTION | BILLING

## How to Run

1. Open https://livesql.oracle.com
2. Run files in this order:
   - 01_sequences.sql
   - 02_create_tables.sql
   - insert_data.sql
   - trigger.sql
   - procedure.sql
   - view.sql
